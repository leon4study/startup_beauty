## ⚠️ 이 조사에서 나온 가장 중요한 결과

**GLOU가 "경쟁 공백"이라고 쓴 자리에 이미 사업자가 있습니다.**

하이어다이버시티의 **하이어비자는 서울 거주 외국인 유학생의 81% 이상이 사용**하고 있고, **전국 105개 이상 대학 부처와 협약**을 맺었습니다. 저희가 Q1·Q2·Q3에서 "대학 국제처를 통한 접근 경로가 후발주자의 진입 장벽"이라고 쓴 부분은 사실과 다릅니다. 그 경로는 이미 선점되어 있습니다.

다만 **하는 일은 겹치지 않습니다.** 하이어비자는 외국인등록증 발급 대행·임대차 신고 같은 **체류 행정**이고, 리뷰나 장소 추천 기능은 확인되지 않았습니다. 따라서 판단은 둘 중 하나입니다.

1. 경쟁자로 보고 같은 경로를 뚫는다 → 승산이 낮음
2. **이미 대학 접점을 가진 사업자를 제휴 대상으로 본다** → 행정을 마친 유학생에게 생활 정보가 필요한 시점이 바로 이어지므로 연결 지점이 분명함

문서에는 2번으로 수정하는 것을 권합니다. "장벽이 있다"는 주장보다 "이미 접점을 가진 곳과 붙는다"가 사실에 맞고 심사에서도 검증을 통과합니다.

| 항목 | 내용 |
| --- | --- |

**GLOU 관점**
- 겹치는 것 — 고객(유학생), 접점(대학 국제처), 진입 시점(입국 직후)

- 시사점 — "국제처 접근 경로가 우리 진입 장벽"이라는 서술은 폐기해야 함. 대신 **행정을 끝낸 유학생이 다음으로 겪는 문제(어디서 먹고 어디서 사나)를 저희가 받는 구조**로 위치를 잡는 편이 정확함
- ⚠️ 매출 규모는 확인하지 못함

## 2. 모두닥 — 구조 벤치마크 (리뷰 → 광고)

| 항목 | 내용 |
| --- | --- |
| 설립 | 2017.10. 서울 지역 치과 리뷰로 시작 → 2020 전국 병의원으로 확대 |
| 서비스 | 병원 검색·예약·리뷰, 비급여 진료비 비교 |
| 수익모델 | **광고.** 병원이 주력 치료(교정·제모 등 비급여)를 이벤트로 등록하면 검색결과·병원페이지에 노출 |
| **제휴 병원** | **전국 250개** |
| **누적 리뷰** | **535,680개** (병원당 약 2,142건) |
| 회원·MAU | 회원 100만 명 이상, **MAU 150만** |
| 매출 | 2023 10.0억 → 2024 26.5억(+165%) → **2025 60.8억(+129.8%)** |
| 수익성 | 영업손실 -10.4억 → -7.0억 → -1.1억 (적자 축소). **2025년 1월 월매출 6억·영업이익 1억 달성** |
| 직원당 매출 | 6,149만원 → 1.7억 → **4.2억** |
| 투자 | 시리즈A 60억(2022.02.), 누적 83억 (스트롱벤처스·스프링캠프·스톤브릿지벤처스·데브시스터즈벤처스) |

**GLOU 관점 — 여기서 예상 매출의 기준선이 나옵니다**

| 산식 | 값 |
| --- | --- |
| 제휴처당 연매출 | 60.8억 ÷ 250곳 = **약 2,432만원** |
| 유저당 연매출(ARPU) | 60.8억 ÷ 150만 MAU = **약 4,053원** |
| 제휴처당 필요 리뷰 | 535,680 ÷ 250곳 = **약 2,142건** |

- 매장 수 기준과 이용자 수 기준 두 가지로 예상 매출을 낼 수 있음
- 다만 병원 비급여 진료는 객단가가 수십만 원대라 음식점·카페와 단가가 다름. **그대로 대입하면 과대 추정**이므로, 업종 객단가 차이를 반영해 보정해야 함
- ⚠️ 250개 병원이 모두 유료 광고주인지, 일부는 무료 등록인지는 확인하지 못함

## 1. Yelp UX 핵심 (베낄 것)

Yelp가 "발견→결정"에 강한 이유 = 아래 패턴. ([DesignRush](https://www.designrush.com/best-designs/apps/yelp), [Jane Itkis](https://medium.com/@janeitkis/reflection-point-yelps-patterns-and-flows-92643782b9a))

| # | 패턴 | 내용 | GLOU 적용 |
|---|---|---|---|
| 1 | **최상단 검색바** | "무엇을 / 어디서" — 타이핑하면 자동완성. 검색이 Yelp의 1순위 태스크. | 상단에 `[무엇] near [어디]` 검색바 |
| 2 | **카테고리 아이콘 발견** | 검색바 아래 일러스트 아이콘(식당·헤어·바…) + 현위치 기반. | 카테고리 **아이콘 pill**(화장품·식당·병원·문화·여가) |
| 3 | **비즈니스 카드** | 큰 사진 + **별점(5점)** + 리뷰 수 + 가격($$) + 카테고리 + 거리. | 카드에 썸네일·별점·리뷰수·가격·**외국인친화 배지** |
| 4 | **리스트 + 지도** | 목록과 지도가 나란히(구글맵과 같은 친숙한 패턴). | 리스트 + **지도 자리(placeholder)** 병치 |
| 5 | **필터 카루셀** | 평점·가격·거리·특징으로 좁히기. | 평점·외국인친화 + **국가/인종 필터** |
| 6 | **상세: 사진→평점→액션** | 히어로 사진 + 평균 평점 크게 + **길찾기·전화** 버튼 + 리뷰. | 상세에 평점요약·분포바·길찾기 버튼 + 리뷰 |
| 7 | **다중 진입점** | 검색 / 홈 갤러리 / 탭 내비. | 검색·카테고리·지역 3진입 |

> 핵심 교훈: **"검색바 + 카테고리 아이콘 + 사진 있는 카드 + 리스트·지도"** 가 Yelp스러움의 정체. 우리 프로토타입에 이 뼈대를 얹는다.

## 2. 외국인이 한국 앱을 불편해하는 이유 (피할 것)

한국은 IT 강국인데도 외국인 체감은 정반대. ([BusinessKorea](https://www.businesskorea.co.kr/news/articleView.html?idxno=222774), [Korea Times](https://www.koreatimes.co.kr/business/tech-science/20250418/local-maps-gain-popularity-but-leave-foreigners-unsatisfied), [South of Seoul](https://blog.southofseoul.net/struggling-with-english-naver-maps-heres-why-it-happens/))

| 페인 | 내용 | GLOU가 취할 태도 |
|---|---|---|
| **지도 영어 데이터 부실** | 네이버·카카오가 다국어를 "지원"은 하나 건물·장소·교통 **영어 데이터가 미비**, **영문주소·키워드 검색이 안 됨**. 외국인 커뮤니티 불만 1위가 내비. | 지도를 새로 만들기보다 **외국인 관점 큐레이션 레이어** + 영어 우선 |
| **본인인증 붕괴** | 배달·뱅킹·예약이 전부 **카카오→통신사 인증**을 거치는데, 한국번호(RRN/ARC 연동) 없으면 인증 실패 → **전체 체인이 끊김.** ([secondmin](https://secondmin.co.kr/why-korean-online-verification-fails-for-foreigners-pass-kakao-naver-fix-checklist/), [KLifeChoice](https://klifechoice.com/kakaotalk-verification-foreigners-korea/)) | **한국번호 없이도 보고 쓸 수 있게**(읽기·리뷰는 이메일 로그인) |
| **리뷰 신뢰 붕괴** | 네이버 블로그·리뷰가 협찬/광고라 불신 → 외국인은 "Yelp 같은 걸 원해". | **국가·인종별 필터 + 신뢰 설계**([13](13_review_integrity.md)) |
| **국가 리뷰 섞임** | 리뷰가 언어·국가 뒤죽박죽(일본어·영어 혼재)이라 "나에게 맞는지" 판단 불가. | **국가·인종별로 정리**(우리 핵심 차별점) |
| **수도권·관광 편중** | 정보·서비스가 서울·관광지 중심, **지방 체류 외국인 소외**. | **지방 커버리지**를 초기 각도로 |

## 3. ⭐ O/X 경쟁사 비교표

> O=됨/강함, △=부분/약함, X=안 됨. **GLOU 열 = 우리가 목표하는 상태.**

| 기능 (외국인 관점) | **GLOU(목표)** | Yelp | 네이버맵 | 카카오맵 | 구글맵 | 캐치테이블 Global |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| 영어 UI 완성도 | **O** | O | △ | △ | O | O |
| **국가별** 리뷰 필터 | **O** | X | X | X | X | X |
| **인종·피부타입별** 리뷰 | **O** | X | X | X | X | X |
| 한국번호 없이 사용 | **O** | O | △ | △ | O | O |
| 리뷰 신뢰(협찬 차단·투명) | **O** | △ | X | X | △ | △ |
| 현지인처럼/앰배서더 콘텐츠 | **O** | X | X | X | X | X |
| 지도 기반 탐색 | **O**(목표) | O | O | O | O | △ |
| 예약·거래 | △(나중) | △ | O | O | X | O |
| 카테고리 발견 UX | **O** | O | △ | △ | △ | △(식당) |
| 영문·키워드 검색 | **O**(목표) | O | △ | △ | O | O |
| 한국 로컬 데이터 깊이 | △ | X | O | O | △ | O |
| **지방** 커버리지 | **O**(목표) | X | O | O | △ | △ |

**읽는 법**: 우리 **빈칸이 곧 기회** — **국가별·인종별 리뷰 필터 + 앰배서더 콘텐츠**는 6개 앱 중 **아무도 O가 없음**. Yelp는 UX는 좋지만 한국 로컬·지방·국가필터가 없고, 네이버·카카오는 로컬은 강하나 영어·리뷰신뢰·외국인관점이 약함. → **"한국 로컬 데이터 위에 Yelp UX + 국가/인종 필터 + 지방"** 이 우리 자리.

## 4. GLOU UX 체크리스트 (프로토타입 반영)

- [x] 카테고리 아이콘 pill (화장품·식당·병원·문화·여가)
- [x] **국가/인종 필터**(핵심) + 내 그룹 먼저
- [ ] 최상단 **검색바** ("무엇 near 어디")
- [ ] 카드에 **썸네일 + 별점 + 리뷰수 + 가격 + 외국인친화 배지**(영어가능·한국번호불필요·혼자가능)
- [ ] **리스트 + 지도 자리** 병치
- [ ] 상세: 평점 요약·**분포 바** + 길찾기·전화 버튼
- [ ] **영어 우선** 카피 + 한국번호 없이 열람
- [ ] 지방 지역 노출(서울·부산·전주…)

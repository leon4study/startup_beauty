## 0. 한 줄 결론

- **시장 타이밍이 정통으로 맞다.** [사실] 2025년 한국 화장품 수출은 역대 최고 **114억 달러**(전년比 +12.3%)였고, **미국(22억 달러)이 처음으로 중국을 제치고 1위 시장**이 되었다. 미국향 수출은 2021년 8.41억 → 2025년 22억 달러로 2배 이상, 반대로 중국향은 ~48억 → ~20억 달러로 급감했다(personalcareinsights, koreaherald). 동시에 [사실] **따이궁/면세 채널은 구조적으로 붕괴**했다 — 2024.2.1 한국 관세청이 코로나 중 중단했던 규정을 복원해 개인 외국인 구매한도·B2C 화물 배송을 금지하면서 따이궁의 고볼륨 리셀 모델이 차단됐고, 면세 매출은 2015년 수준으로 후퇴했다(koreatimes, seoulz). → **"가치가 빠져나가는 채널(면세·따이궁) → 유입되는 채널(서구 D2C·틱톡샵·UGC)"** 흐름에 정확히 베팅하는 미션.
- **이 미션 10개는 모두 같은 병목 하나를 푼다**: K-뷰티 브랜드(특히 인디·중소)는 해외에서 "**현지 신뢰를 가진 외국인 크리에이터를 찾고·캐스팅하고·콘텐츠를 만들고·반응을 측정**"하지 못한다([사실] "K-뷰티 브랜드는 한국 인플루언서가 아니라 현지의 신뢰받는 목소리를 찾아야 한다" — everything-pr, theinfluencermarketingfactory). 우리 팀의 **180개국 외국인 크리에이터 네트워크**가 바로 이 공급측 자산이다.
- **콜드스타트 해소 = 우리의 유일한 비대칭 우위.** Collabstr·Insense·Aspire 같은 글로벌 마켓플레이스의 진짜 해자는 "**검증된 크리에이터 공급 풀**"이다(Aspire 100만 옵트인 크리에이터, Insense 2만+, Collabstr 마켓). 신규 진입자는 이 공급을 0부터 모아야 하는 **양면시장 콜드스타트**에 죽는다. 우리는 **공급측(외국인 크리에이터)을 이미 보유**한 상태로 시작하므로, 수요측(K-브랜드)만 모으면 되는 **단면 콜드스타트**로 난이도가 반감된다.

### D-1. UGC Bridge — 한국 브랜드 ↔ 글로벌 마이크로 인플루언서 UGC 마켓플레이스 `[C·A]`

- **컨셉**: K-뷰티 브랜드가 셀프서브로 180개국 외국인 마이크로 크리에이터에게 직접 UGC(틱톡/릴스/리뷰영상)를 발주·구매하는 양면 마켓. 1줄: **"Collabstr for K-beauty, 공급측이 이미 채워진."**
- **1차 타겟**: 미국·영·호 진출하려는 한국 인디·중소 뷰티 브랜드(자체 마케팅팀 없음).
- **수익구조**: **거래 take-rate 12~18%**(Insense 7~20% 벤치 중간) + 브랜드 구독($299~400/월, Collabstr/Insense 벤치) + 사용권 애드온(페이드 +30%, 화이트리스팅 +50~100%). [추정] 평균 발주 $300 × take 15% = 건당 $45 + 구독.
- **비교사 벤치**: Collabstr(무료+$299구독+수수료), Insense(구독+7~20% 마켓피), Aspire(구독 $2k+). **우리 차별점**: 이들은 일반 카테고리·범용 크리에이터, 우리는 **K-뷰티 전용 + 외국인 현지 크리에이터** 버티컬.
- **★콜드스타트 해소**: Collabstr/Insense의 해자는 "검증 크리에이터 풀"이다 — 신규 진입자는 양면 콜드스타트로 죽는다. **우리는 180개국 외국인 크리에이터 네트워크를 day-1에 공급으로 투입** → 수요측(브랜드)만 영업하면 되는 단면 문제로 전환. 리뷰 RAG로 "이 제품엔 어떤 톤·소구점이 먹히는지" 크리에이터 매칭까지 자동화.
- **팀자산**: ①(네트워크=공급) + ②(리뷰 RAG=매칭) + ③(뷰티). **3개 전부.**
- **적합도**: ★★★★ (Contents·AI). **GLOU와의 거리: 가까움**(GLOU의 콘텐츠 자산을 B2B로 수익화). ※ [12_idea_scoring.md] #4 UGC Bridge = 38.5점 ✅Go.

### D-2. CastKorea — 외국인 크리에이터 캐스팅 에이전시(매니지드 서비스) `[C]`

- **컨셉**: UGC Bridge가 셀프서브라면, 이건 **매니지드(풀서비스)**. 브랜드가 캠페인 목표만 주면 우리가 적합한 외국인 크리에이터 캐스팅·브리프·계약·정산·리포팅을 대행. 1줄: **"K-뷰티 해외 캠페인의 캐스팅 디렉터."**
- **1차 타겟**: 해외 캠페인은 하고 싶지만 셀프서브 운영 리소스가 없는 중견 브랜드·해외마케팅팀.
- **수익구조**: **리테이너 $5,000~/월 + 크리에이터 지출의 15~30% 마진**(에이전시 표준) 또는 **리테이너 + 매출쉐어(performance bonus)** 하이브리드. [사실] "54% 브랜드가 리테이너/파트너십 채택" 추세 정합.
- **비교사 벤치**: 일반 인플루언서 에이전시(NC Media 등 플랫 리테이너), Aspire(SaaS형). **우리 차별점**: [사실] 2026 "캐스팅 시대"의 핵심은 "크리에이터·오디언스·브랜드 간 보이지 않는 친화도를 읽는 것"(Forbes) — 우리는 외국인 인사이트로 **문화적 핏(cultural fit)을 직접 판별**.
- **★콜드스타트 해소**: 에이전시는 "섭외 가능한 검증 크리에이터 명부"가 자산. 우리는 그 명부를 **이미 보유**하므로 첫 캠페인부터 즉시 캐스팅 가능 — 경쟁 에이전시는 매 캠페인마다 콜드 아웃리치로 시간·신뢰를 소모.
- **팀자산**: ①(네트워크) + ③(뷰티). **2개.** (+②로 매칭 고도화)
- **적합도**: ★★★ (서비스형이라 트랙션 데모는 약하나 매출 즉시 발생). **GLOU와의 거리: 가까움.**

### D-3. K-AffiliateNet — K-뷰티 전용 어필리에이트 네트워크 `[C·A]`

- **컨셉**: 외국인 크리에이터 ↔ K-뷰티 브랜드를 **성과형(어필리에이트)**으로 연결하는 네트워크. 링크·할인코드 발급, 트래킹, 정산을 우리가 운영. 1줄: **"K-뷰티판 ShareASale/LTK, 공급은 우리 외국인 풀."**

## 4. 콜드스타트 해소 — 우리 인플루언서 자산의 구조적 우위 (종합)

> 미션 D 10개 전부가 **양면시장 또는 공급 의존형**이다. 일반 진입자는 다음 콜드스타트로 죽는다:

| 서비스 유형 | 일반 진입자의 콜드스타트 병목 | 우리 자산이 푸는 방식 |
|---|---|---|
| UGC 마켓(D-1) | 검증 크리에이터 공급 0부터 모집 | **180개국 외국인 크리에이터 = day-1 공급** → 단면 문제로 전환 |
| 캐스팅 에이전시(D-2) | 매 캠페인 콜드 아웃리치 | 보유 명부로 **즉시 캐스팅**, 문화핏 판별 |
| 어필리에이트(D-3) | 퍼블리셔(크리에이터)측 모집 | 활성화 가능 퍼블리셔 **즉시 N명 약속** |
| 공동구매·소싱(D-4) | 모객(수요 집단) 부재 | 크리에이터 팔로워 = **공구 참여 풀** |
| 틱톡샵/라이브 대행(D-5) | 전환내는 현지 호스트 부재 | **LIVE 호스트·어필리에이트 즉시 공급** |
| 풀퍼널(D-6) | "결과 낸 크리에이터·데이터" 신뢰 | 크리에이터 + **리뷰 RAG 반응 데모** |
| 구독박스(D-7) | 높은 CAC | 크리에이터 언박싱 = **자체 모객 UGC** |
| 후기 라이선싱(D-8) | 거래할 콘텐츠 인벤토리 0 | 외국인 후기 = **day-1 인벤토리** |
| 시딩 플랫폼(D-9) | 시딩 받을 마이크로 풀 부재 | 보유 마이크로 풀로 **즉시 시딩** |
| 반응분석 SaaS(D-10) | 분석할 데이터 부재 | 캠페인이 **데이터 자가 생성** |

**[추정] 핵심 통찰**: 비교사들(Collabstr·Insense·Aspire)의 가치는 80%가 "수년간 모은 공급 풀"에 있다. 우리는 그 풀(외국인 크리에이터 네트워크)을 **이미 가진 상태로 출발**하므로, 본질적으로 **"공급을 가진 자가 수요를 모으는 게임"**이다 — 이건 콜드스타트의 절반을 건너뛴다.

## 5. 깔때기(Funnel) — 10개는 따로가 아니라 하나의 파이프라인

```
[공유 자산]  180개국 외국인 크리에이터 네트워크 + K-뷰티 리뷰 RAG
        │
  ┌─────┼──────────────────────────────────────────────┐
  │ 획득 │ D-9 시딩 → 크리에이터에 제품 전달               │
  │ 제작 │ D-1 UGC마켓 / D-2 캐스팅 → 후기·콘텐츠 생산      │
  │ 유통 │ D-3 어필리에이트 / D-5 틱톡샵·라이브 → 판매전환  │
  │ 재활용│ D-8 라이선싱 → 콘텐츠 광고소재로 재판매          │
  │ 묶음 │ D-7 구독박스 / D-4 공구 → 커뮤니티 커머스         │
  │ 측정 │ D-10 ReactionLens → 반응 데이터화(B2B 수익+해자) │
  │ 턴키 │ D-6 FullFunnel → 위 전부를 패키지로 판매          │
  └──────┴──────────────────────────────────────────────┘
```

**[추정] 모두의창업 R1 권고**: 10개를 다 하지 말고 — **D-1(UGC마켓, 공급우위 즉시 증명) + D-10(ReactionLens, 데이터 데모=증거) + D-6(FullFunnel, 번들 매출)** 3개를 코어로 피칭. 본진 GLOU는 B2C 큐레이션으로 유저·반응 데이터를 모으고, 그 데이터가 D-10을 먹이는 듀얼트랙([12_idea_scoring.md] 권고와 정합).

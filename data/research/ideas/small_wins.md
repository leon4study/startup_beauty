# 창업자 원안 + 작은 시작 아이디어 (small wins)

> 큰 플랫폼을 한 번에 짓지 말고, **불편한 것 하나를 딱 고치는 작은 것부터** 내놓는다. 반응 좋으면 키운다.
> 핵심: 아래 작은 것들 다수가 **큰 서비스(GLOU·로컬 리뷰 통합·SkinMatch 등)의 입구**다 — 작게 검증 → 자연스럽게 확장. 작성 2026-07-02

---

## 0. 창업자 원안 — 로컬 리뷰 통합 + 현지인처럼 즐기기 (핵심 B2C)
외국인 입장에서 "뭘 하고 싶은데" 부터 출발한다.
- **위치 기반 발견**: 지금 내 위치(또는 지정 위치) 기준 가까운 미용실·카페·맛집.
- **못 보던 한국 리뷰 열어주기**: 외국인이 접근 어려운 **네이버·카카오 리뷰 평점을 바로 영어로** + 플랫폼별 장·단점 비교.
- **현지인처럼 즐기는 법**: "한국인은 여기서 어떻게 먹고 즐기나" — 예: 삼겹살엔 소주, **요즘 MZ는 소주 대신 하이볼·제로소주** 같은 최신 조합·트렌드. 관광객이 아니라 현지인처럼.
- **외국인 전용 리뷰**: 외국인들끼리의 리뷰 레이어(유료 프리미엄 or 오픈해서 더 유용하게).
- **차별점(해자)**: "현지인처럼 즐기는 법"은 **우리 인플루언서·콘텐츠 자산**이 있어야 됨 → 구글맵·트립어드바이저가 못 하는 부분.
- **데이터(합법)**: 평점·장소는 **구글 Places API(공식)** + 네이버/카카오는 공식 지도 API 범위 내로, **외국인 리뷰는 자사 1차 데이터**(가장 큰 해자).

## 1. 작은 시작 아이디어 (불편 하나 → MVP → 확장)

| 불편(딱 하나) | 작은 시작(MVP) | 좋으면 이렇게 확장 |
|---|---|---|
| 한글 메뉴판, 뭐 들었는지 모름 | 메뉴 사진 → 재료·알러지·비건 여부 영어로 (봇) | 식이필터 다이닝 지도 |
| 미용실서 원하는 스타일 설명 못 함 | 스타일 사진+요청을 **한국어 카드**로 생성 | 살롱 예약·매칭 |
| 한글 주소 못 읽음/택시 설명 못 함 | 주소 붙여넣기 → 영어+지도핀+기사용 카드 | 정착·교통 도우미 |
| "지금 열었나?" 영업시간 헷갈림 | 가게명 → 영업/브레이크타임 영어 즉시 | 로컬 리뷰 통합(원안) |
| 화장품 뒷면 한글 성분 모름 | 성분 스캔 → 알콜·향료·자극 3줄 요약 | SkinMatch(성분 추천) |
| 네이버 블로그 후기가 협찬 같음 | 링크 넣으면 협찬 가능성 배지 | 리뷰 신뢰도 통합 |
| 배달앱을 한국번호 없어 못 씀 | 대신 주문해주는 폼 | 정착 OS |
| 약국서 증상 설명 못 함 | 증상 → 약사용 한국어 카드 + 추천 성분 | 의료 내비 |
| 한국 사이즈 헷갈림(옷·신발·용량) | 사이즈·용량 변환기 | 쇼핑 가이드 |
| 이 카드/페이 여기서 되나? | 가게 → 외국카드·현금·페이 가능 표시 | 결제 가이드 |
| 혼밥·혼술 눈치 보임 | 혼자 가기 좋은 곳 필터 리스트 | 로컬 큐레이션 |
| 시술 다운타임 모름 | 시술명 → 회복기간·주의 영어로 | 메디컬 뷰티 |
| 계산·나이·존댓말·신발 등 매너 | 상황별 "한국 매너" 치트시트 | 정착 콘텐츠 |
| 이 제품 본국보다 싼가? | 제품 스캔 → 본국 가격 비교 | K-뷰티 쇼핑 |

## 2. 시작 규칙 (작게 → 빠르게 → 살리기)
1. 첫 버전은 **앱 말고 봇·폼·콘텐츠 한 장**이면 충분(노션·인스타·챗봇).
2. **딱 한 페인 × 딱 한 동네/한 카테고리**로 좁혀 시작.
3. 며칠 만에 내놓고, 반응(사용·재방문·유료의향)을 보고 살릴지 결정.
4. 살아나면 → 위 "확장" 방향의 큰 서비스로 흡수. (작은 것 = 큰 서비스의 사용자·데이터 입구)

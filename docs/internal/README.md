# docs/internal — 민감 자료 (git 미추적)

**법적 리스크 검토처럼, 민감해서 git에 남기고 싶지 않은 자료**만 여기에 둡니다.

- 이 폴더의 파일은 **git에 커밋되지 않습니다**(`.gitignore`). 폴더는 `.gitkeep`으로만 유지.
- 실제 파일은 **팀 채널(드라이브 등)로만 공유**하세요.

> 참고: 지금 단계에선 `docs/business/`의 자료도 대부분 **팀 내부용**입니다(전략·리서치·기획). 그건 git으로 팀과 공유해도 되는 것들이고, 여기(`internal`)에는 **git에도 남기지 않을 민감 자료**만 둡니다. 투자자·심사·대중 대상 대외 발표물은 나중에 **피치덱·랜딩으로 따로 정제**합니다.

## 3. 단계별 지원금 (전국 기준)
- **R1**: MVP 제작 지원금 평균 600 ~ 최대 1,000만원 + 규제스크리닝
- **R2**: 사업화지원금 평균 800 ~ 최대 1,000만원
- **R3**: 내년 사업화지원금 **1억원** + 투자 우선검토
- **R4 TOP10**: 1위 → R3 지원 + **상금 5억 + 투자 5억(검토) + CES 참관**, 2~5위 상금

## 4. 우리(중앙대 1라운드)가 지금 받는 것
1. **창업활동자금 200만원** — 클린카드 지급, **~8.31까지 사용**, 창업활동보고서 작성(멘토 확인 → 다음 라운드 추천 근거).
2. **AI 바우처 100만원** — 월 50만원 × 2개월. 모두의창업 플랫폼의 **283개 공급기업 / 407개 솔루션** 중 선택, 멘토기관 통해 신청. (신청 1차 6.15~6.24 / 2차 7.20~7.27)
3. **책임멘토링** — 라운드별 최소 4회(1:1 3회 이상 + 그룹 1회 이하), 대면 원칙(6.10~7.22).

## 5. 중앙대 라운드별 보육 내용
- **1R (CAU Pre-Round / 발굴·진입)**: 기업가정신 특강, 아이디어 고도화 BM 원데이, 네트워킹.
- **2R (Foundation / 아이템 검증)**: 고객 인터뷰·설문(시장 수요 분석), BM 피벗·수익구조, 기술 기반 실증(가설·실험설계).
- **3R (Development / 제품 구현)**: 시제품 제작 인프라(교내 메이커), 기술 고도화 멘토링, **IP/특허 출원 전략**.
- **파이널 (Scale-up)**: IR 피치덱, 투자자 밋업, 글로벌·오픈이노베이션.

## 6. R1 평가 대비 시사점 (9월 지역오디션 10분 발표)
- 심사 핵심: **실제 트랙션(수요 검증)** > 아이디어. → MVP로 외국인 사용자·제휴 매장 **실수치**를 모아야 함.
- "AI 추천"은 말로만 두지 말고 **보유 자산(Kbeauty RAG: 아마존·틱톡 리뷰 + 성분 기반)** 으로 데모 가능함을 증명.
- 200만원은 **외주 개발/리서치**에 집중, AI 바우처는 마케팅·콘텐츠·데이터 솔루션에 배정.

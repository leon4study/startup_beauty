# 사업계획서 버전 이력

**파일명 규칙: `YYYY-MM-DD_이름.docx`** — 날짜가 클수록 최신입니다.

## ⭐ 현재 최신 = `2026-08-15_1R_사업계획서_피드백반영본_15pt.docx` / `_10pt.docx`

15pt본과 10pt본은 같은 내용의 조판 차이입니다. 10pt본이 이미지 3장과 글자 400자가 더 들어가 있습니다.

| 날짜 | 파일 | 상태 | 내용 |
| --- | --- | --- | --- |
| 2026-07-29 | `2026-07-29_GLOU_사업계획서.docx/.odt/.pdf` | 구버전 | 최초 통합본. 팀원 이름이 `[성명]`, 재무 ③④가 `재산출`로 비어 있음 |
| 2026-07-31 | `2026-07-31_GLOU_사업계획서_1차수정본.docx` | 구버전 | 팀장 수정본. 실명 기재, 재무 ③④ 숫자 채움(근거는 미기재) |
| 2026-08-14 | `2026-08-14_1R_사업계획서_제출본.docx` | 구버전 | 1R 제출본. 문제–솔루션–시장진입을 1:1로 연결, TAM/SAM/SOM Bottom-up 산정, GTM 단계 도입 |
| **2026-08-15** | **`2026-08-15_1R_사업계획서_피드백반영본_15pt.docx`** | **최신** | 피드백 반영본(15pt 조판). 이미지 11→6장 |
| **2026-08-15** | **`2026-08-15_1R_사업계획서_피드백반영본_10pt.docx`** | **최신** | 같은 내용, 10pt 조판. 이미지 9장, 본문 9,108자 |

## 0814 제출본이 받은 피드백

| # | 피드백 | 반영 방향 |
| --- | --- | --- |
| 1 | 포함된 그림의 선명도 개선 필요 — 글씨가 깨져 보임 | ❌ **0815본에서 해결되지 않음.** 15pt본은 6장 중 5장, 10pt본은 9장 중 7장이 여전히 300 DPI 미만 → [그림_선명도_점검.md](../그림_선명도_점검.md) |
| 2 | 문장은 가급적 개조식 작성 필요(동그라미·바 형태) | ⚠️ **미확인.** `●`·`–` 기호 개수가 0814본과 같음(1개·3개). 조판만 바뀌고 문장 형태는 그대로일 가능성 |
| 3 | 솔루션 선택 근거 — 표의 "단독으로 부족한 이유"가 무슨 말인지 모르겠음 | 열 이름을 풀어 쓰기. "단독"이라는 축약이 원인 |
| 4 | 솔루션에서 국적·인종에 따라 필터링된다는 개념을 부각 | ✅ **반영됨.** 본문에서 '국적' 15→24회, '인종' 7→15회, '필터' 2→4회로 늘어남 |

## 새 버전이 생기면

1. `YYYY-MM-DD_이름.docx`로 이 폴더에 넣습니다
2. 위 표에 한 줄 추가하고, ⭐ 표시를 옮깁니다
3. 이전 버전은 지우지 않습니다 — 심사에서 "무엇이 어떻게 바뀌었나"를 물으면 근거가 됩니다

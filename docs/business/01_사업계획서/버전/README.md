## 0814 제출본이 받은 피드백

| # | 피드백 | 반영 방향 |
| --- | --- | --- |
| 1 | 포함된 그림의 선명도 개선 필요 — 글씨가 깨져 보임 | 화면 캡처를 2배 배율 또는 벡터로, docx 이미지 압축 해제 |
| 2 | 문장은 가급적 개조식 작성 필요(동그라미·바 형태) | 서술 문단을 `●` `–` 불릿으로 분해 |
| 3 | 솔루션 선택 근거 — 표의 "단독으로 부족한 이유"가 무슨 말인지 모르겠음 | 열 이름을 풀어 쓰기. "단독"이라는 축약이 원인 |
| 4 | 솔루션에서 국적·인종에 따라 필터링된다는 개념을 부각 | 국적·인종 필터를 단독 항목으로 올리고 캡처를 크게 |

## 새 버전이 생기면

1. `YYYY-MM-DD_이름.docx`로 이 폴더에 넣습니다
2. 위 표에 한 줄 추가하고, ⭐ 표시를 옮깁니다
3. 이전 버전은 지우지 않습니다 — 심사에서 "무엇이 어떻게 바뀌었나"를 물으면 근거가 됩니다

## 1. 아이디어의 개발 방안

### 1-1. 서비스 구성

Q1에서 확인한 문제를 네 가지 기능으로 풀도록 구성하였습니다.

**[표 1] 문제와 대응 기능**

| Q1에서 확인한 문제 | 대응 기능 | 작동 방식 |
| --- | --- | --- |
| 리뷰가 광고인지 구분되지 않음 | 맥락 공개 리뷰 | 작성자의 국적·체류기간·피부타입과 협찬 여부를 리뷰와 함께 표시 |
| 외국인을 하나의 집단으로 보는 리뷰만 있음 | **Fit Review¹** | 이용자가 입력한 조건과 일치하는 작성자의 리뷰만 걸러서 보여줌 |
| 방문 전에 이용 조건을 알 수 없음 | **GLOU Check²** | 영어 가능·외국 카드 결제·한국 번호·예약·혼자 방문·가격대를 항목으로 표준화 |
| 정보와 사람이 여러 채널에 흩어져 있음 | 커뮤니티(Lounge) + 앰배서더³ 랭킹 | 같은 국적의 먼저 온 이용자와 그 사람이 다녀온 장소를 한 화면에 노출 |
| 매장에 외국인 고객 접점이 없음 | 숏폼 콘텐츠 → 이벤트·쿠폰 | 콘텐츠를 본 뒤 쿠폰을 신청하고 방문한 다음 리뷰를 남기는 흐름 |

### 1-2. 데이터 확보 방안

필요한 데이터를 장소·유저·리뷰 세 가지로 나누어 확보 경로를 정하였습니다.

**장소 데이터**는 공공 개방 데이터와 한국관광공사 TourAPI⁴의 관광정보를 결합하여 구성하겠습니다. 소상공인시장진흥공단의 상가(상권)정보는 전국에서 영업 중인 상가업소의 상호명·업종·주소와 경도·위도를 제공하고 분기마다 갱신되며(2026년 6월 30일 기준본), 표준산업분류 10차를 따라 업종이 대분류 10개·중분류 75개·소분류 247개로 나뉘어 있어 카테고리 체계를 그대로 쓸 수 있습니다. 여기에 TourAPI의 관광정보 약 26만 건을 더해 초기 장소 목록을 만들겠습니다. 두 자료 모두 공식 개방 데이터이므로, 다른 플랫폼의 리뷰를 무단으로 수집하지 않고도 장소 데이터베이스를 채울 수 있습니다.

**유저 데이터**는 가입 시점, 마이페이지, 리뷰 작성 시점 세 곳으로 나누어 받겠습니다. 가입 단계에서는 국적과 언어만 받아 가입 도중에 이탈하지 않도록 하고, 피부타입·식문화·알레르기 등 Fit Review에 쓰이는 항목은 마이페이지에서 본인이 원할 때 선택 입력하도록 분리하였습니다.

**리뷰 데이터**는 앰배서더와 파일럿 참가자가 직접 작성하는 방식으로 확보하겠습니다. 초기에는 리뷰가 없어 조건 필터를 걸면 결과가 비어 버리므로, 지역과 카테고리를 좁혀(1개 대학 인근, 음식점·카페·뷰티 30개 매장) 그 범위 안에서 먼저 리뷰를 모으겠습니다.

### 1-3. 유저 확보 방안

온라인에서는 공식 SNS 채널의 콘텐츠로 유입을 만들고, 오프라인에서는 대학 국제처와 한국어교육원, 외국인 커뮤니티 및 언어교환 모임을 통해 직접 접촉합니다. 국적별로 주로 쓰는 채널이 다르므로(베트남은 페이스북, 중국은 샤오홍슈 계열) 단일 채널 홍보가 아니라 국적별로 나누어 운영하겠습니다.

**[표 2] 유입 경로와 접점 시점**

| 경로 | 방법 | 접점 시점 |
| --- | --- | --- |
| 대학 국제처·한국어교육원 | 신입 유학생 오리엔테이션에서 안내, 국적·관심사 입력 후 자국 리뷰 피드 노출 | 입국 직후 |
| 국가별 온라인 커뮤니티 | 국적별 채널에 맞춘 콘텐츠 배포 | 입국 전~초기 |
| 오프라인 모임 | 언어교환 모임·외국인 커뮤니티 현장 참여 | 상시 |
| 공식 SNS | 외국인 관점의 장소 콘텐츠 | 상시 |

입국 직후를 첫 접점으로 잡은 이유는, 어학연수 비자(D-4-1⁵) 대상자가 입국 전 2학기 이상 등록을 확정하고 오기 때문에 최소 6개월에서 1년의 체류가 보장되고, 이 시점에 비자·외국인등록증(ARC⁶)·은행 계좌·전화번호 등 행정 절차가 몰려 정보 수요가 가장 높기 때문입니다.

### 1-4. 플랫폼 활성화 계획

리뷰 작성은 첫 리뷰 미션, 앰배서더 선정, 작성 부담 줄이기 세 가지 방법으로 유도하겠습니다. 리뷰가 쌓이지 않으면 서비스 자체가 성립하지 않기 때문입니다.

첫째, 가입 후 3일 이내에 첫 리뷰를 작성하는 미션을 부여하고 완료 시 쿠폰 또는 포인트를 제공합니다. 둘째, 리뷰를 많이 쓴 이용자를 국적별·지역별 앰배서더로 선정하여 랭킹 화면에 이름을 올리고 브랜드 협찬으로 연결합니다. 셋째, 별점과 태그를 고르는 것만으로 리뷰 한 건이 완성되게 하고, 사진 첨부는 필수 조건에서 뺐습니다.

이 방식으로 실제 성과를 낸 사례가 있습니다. 비건 이용자를 위한 리뷰 플랫폼인 HappyCow는 개인 조건으로 장소를 거르는 방식과 앰배서더 제도를 함께 운영하여 185개국 24만 곳 이상의 등록 업소와 187만 건 이상의 리뷰를 확보하였고, 현재 600명 이상의 앰배서더가 활동하고 있습니다. 국내에서는 화해가 피부타입·연령별 랭킹으로 리뷰를 걸러 보여주는 방식으로 650만 건의 리뷰를 축적하였습니다. 두 서비스 모두 큰 자본을 들이지 않고, 나와 조건이 같은 사람의 리뷰를 보여준다는 점 하나로 이용자가 직접 리뷰를 쓰게 만들었습니다.

### 1-5. 효과성 검증 지표

파일럿에서 아래 지표를 이용 전·후로 측정하여 성장 전략의 근거로 사용하겠습니다. 목표값은 1차 실증 규모(30개 매장) 기준입니다.

**[표 3] 검증 지표와 1차 파일럿 목표**

| 구분 | 지표 | 목표 |
| --- | --- | --- |
| 콘텐츠 | 등록 리뷰 수(국적별 분리 집계) | 매장당 5건 × 30개 = 150건 |
| 탐색 | 리뷰 조회수, 저장·클릭 수 | 리뷰 1건당 조회 20회 이상 |

| 지속 | 방문자 대비 리뷰 작성률 | 25% 이상 |

### 2-1. 제품과 팀

웹 프로토타입 개발을 완료하였습니다. 화면 시안이 아니라 실제로 클릭하여 화면 이동을 확인할 수 있는 형태이고 인터넷 주소로 공개되어 있어, 심사 과정에서 바로 시연할 수 있습니다. 웹과 모바일을 하나의 코드로 만들어 화면 크기에 따라 배치가 바뀌며, 모바일에서는 하단 탭으로 전환됩니다. 로그인은 구글 계정 연동을 붙여 실제 인증까지 동작을 확인하였습니다. 다만 아직 서버를 붙이지 않아 작성한 리뷰가 저장되지는 않으며, 화면과 데이터 구조를 저장 기능에 맞추어 설계해 두었으므로 계정을 확보하면 연동만으로 동작합니다.

이 MVP를 외주 없이 팀 내 인력이 직접 제작하였기 때문에, 조사에서 나온 의견을 제품에 반영하는 데 걸리는 시간이 짧습니다. 초기 유입에 필요한 콘텐츠 제작과 외국인 접점도 팀 안에 있습니다. 팀장은 K-뷰티와 K-라이프스타일을 주제로 외국인을 대상으로 하는 크리에이터로 활동하고 있습니다.

### 2-2. 조사 결과를 제품에 반영한 내역

Q1의 조사 결과를 기능으로 옮긴 내역은 다음과 같습니다. 응답자 수가 적으므로 조사 결과를 시장 규모의 근거로는 쓰지 않았고, 만들 기능과 우선순위를 정하는 데에만 사용하였습니다.

**[표 5] 조사 근거와 구현 결과**

| 근거 | 구현한 것 |
| --- | --- |
| 수요조사 1순위 기능(국적별 리뷰 지도) | Fit Review 필터를 첫 화면 기능으로 구현 |
| 피부타입이 비슷한 사람의 K-뷰티 리뷰 요구 | 마이페이지 피부타입 입력, 뷰티 카테고리 필터 |
| 본인인증·한국 번호 장벽 응답 | GLOU Check에 한국 번호 필요 여부, 외국 카드 결제 가능 여부 추가 |
| 광고·협찬 구분 불가 응답 | 작성자 정보와 협찬 여부를 리뷰에 함께 표시 |
| 국제처 면담(입국 초기 문의 집중) | 초기 고객을 어학연수생·유학생으로 좁히고 온보딩⁹ 시점을 겨냥 |

2차 조사에서는 응답 100명 이상을 확보해 국적·체류기간·한국어 수준별로 나누어 보겠습니다. 규모와 분포에 대한 근거는 자체 조사가 아니라 법무부 체류외국인 통계, 한국교육개발원 유학생 통계, 통계청 이민자 체류실태 및 고용조사 원자료로 대신하겠습니다.

### 2-3. 남은 준비

대학과의 협의는 진행 중이며 파일럿은 확정되지 않았습니다. 협의가 늦어질 경우 언어교환 모임과 국가별 온라인 커뮤니티에서 참가자를 직접 모집하는 방식으로 대체할 수 있도록 두 경로를 함께 준비하고 있습니다.

개인정보는 받는 양을 줄이는 쪽으로 설계하였습니다. 국적·인종·피부타입 등 민감할 수 있는 항목은 모두 선택 입력이며, 가입 단계가 아니라 마이페이지에서 본인이 원할 때 입력하도록 분리하였고, 리뷰에 나타나는 정보도 이용자가 고른 항목만 보이도록 하였습니다. 조사 과정에서 수집한 이름·이메일·전화번호는 분석 전에 식별자로 바꾸어 사용합니다. 개인정보 처리방침과 이용약관은 회원 가입 기능을 공개하기 전에 작성하겠습니다.

## 3. 차별화 방안

### 3-1. 기존 서비스와의 차이

**[표 6] 기존 서비스와 GLOU 비교**

| 구분 | 기존 서비스 | GLOU |
| --- | --- | --- |
| 리뷰 기준 | 한국인 이용자 기준의 별점과 후기 | 작성자의 국적·체류기간·피부타입·식문화가 함께 표시되는 리뷰 |
| 탐색 방식 | 전체 평점 순 정렬 | 나와 조건이 같은 사람의 리뷰만 보는 Fit Review |
| 정보 구조 | 텍스트 후기 중심 | 이용 조건을 항목으로 표준화한 GLOU Check |
| 콘텐츠 생산자 | 일반 이용자 또는 협찬 크리에이터 | 국적별·지역별 앰배서더가 순위와 함께 노출 |
| 매장 연결 | 화면에 노출하는 데까지 | 쿠폰·이벤트로 실제 방문까지 연결하고, 방문 수와 리뷰를 데이터로 확보 |

### 3-2. 화면 설계 — 레퍼런스 조사에 근거한 선택

외국인 이용자가 한국 서비스를 쓸 때 어디에서 막히는지 확인하기 위해, 외국인 대상 한국 서비스와 해외 리뷰·커뮤니티 서비스를 직접 설치하여 화면 단위로 비교하였습니다. 어떤 서비스가 좋다는 평가가 아니라 각 화면에서 무엇을 보고 무엇을 못 보는지를 기준으로 정리하였고, 그 결과를 MVP 화면에 그대로 반영하였습니다.

**[표 7] 화면 조사와 GLOU 적용**

| 조사한 서비스 | 화면에서 확인한 점 | GLOU에 적용한 것 |
| --- | --- | --- |
| 크리에이트립 | 필터에 "English Available"이 별도 항목으로 있고, 상품 카드에 쿠폰 배지가 붙어 있음 | 영어 가능 여부를 태그가 아닌 필터 항목으로 올리고, 장소 카드에 쿠폰 표시를 붙임 |
| 캐치테이블 글로벌 | 한국 전화번호 없이 예약이 가능하다는 점을 화면에서 먼저 알려 줌 | "한국 번호 필요 없음"을 장소 상세 상단에 고정 표시 |
| 네이버지도·카카오맵 | 한국어 사용자 기준으로 정보량이 많아 처음 온 외국인은 어디부터 볼지 판단이 어려움 | 장소 상세에서 먼저 보여줄 항목을 다섯 개로 제한 |
| Yelp | 하단 탭이 다섯 개를 넘지 않고 각 탭 이름이 한 단어임 | 모바일 하단 탭을 다섯 개로 제한하고 아이콘과 한 단어로 구성 |
| 샤오홍슈 | 두 칸 격자 피드와 짧은 글 형식이라 읽는 부담이 적음 | 커뮤니티·숏폼을 두 칸 격자로 배치하고 사진 첨부를 필수에서 제외 |
| 당근 | 지역 단위 커뮤니티가 지도·거래와 분리된 별도 탭으로 존재 | 커뮤니티를 리뷰와 섞지 않고 별도 탭으로 분리 |
| 무신사 | 체형 조건을 넣으면 그 조건의 후기만 보이는 필터가 리뷰 안에 있음 | Fit Review 필터를 별도 화면이 아니라 리뷰 목록 안에 두어 한 번의 체크로 전환 |

이 조사에서 공통으로 확인한 것은, 외국인 이용자가 막히는 지점이 언어 자체보다 "이 가게에서 내가 결제와 예약을 할 수 있는가"를 방문 전에 알 수 없다는 데 있다는 점이었습니다. 이에 설명을 읽지 않아도 화면에 보이는 것만으로 뜻이 통하도록(저맥락¹⁰ 구성) 항목 수를 제한하고, 판단에 필요한 정보를 장소 상세 첫 화면에 고정하였습니다.

### 3-3. 차별화가 통한다는 근거

핵심 차별점은 화면을 외국어로 번역해 주는 데 있지 않고, 이용자가 입력한 조건에 따라 화면에 나오는 리뷰 목록 자체가 달라진다는 데 있습니다.

이 방식이 구매 결정에 영향을 준다는 것은 국내에서 이미 확인되었습니다. 무신사는 체형이 비슷한 구매자의 후기를 골라 볼 수 있게 하는 등 개인화를 강화한 뒤, 개인화 추천 영역의 구매 전환율이 약 3배 증가하였다고 밝힌 바 있습니다. 저희는 같은 방식을 의류 체형이 아니라 국적·피부타입·식문화에 적용하였습니다.

리뷰 신뢰 문제는 리뷰를 올릴 때 작성자가 어떤 사람이며 협찬을 받았는지를 리뷰 옆에 함께 보여주는 방식으로 해결하겠습니다. 의심 리뷰를 사후에 찾아내 지우는 방식은 운영 부담이 크고 이미 읽은 이용자에게는 소용이 없으므로, 판단에 필요한 정보를 처음부터 함께 보여주어 이용자가 직접 걸러 읽도록 하였습니다.

### 3-4. 후발주자의 진입 장벽

후발 경쟁자가 따라오기 어려운 지점은 대학 국제처를 통해 신입 유학생을 만나는 경로와 국적별 앰배서더 네트워크 두 가지이며, 1차 실증에서 이 둘을 먼저 확보하겠습니다. 국적별 리뷰는 한 나라의 리뷰가 일정 수 이상 쌓여야 다음 이용자에게 쓸모가 생기고 그 이용자가 다시 리뷰를 남기기 때문에, 지역과 국적을 좁혀 그 안에서 먼저 리뷰 수를 채우는 쪽이 유리합니다. 두 경로 모두 사람과 관계로 만들어지는 것이라 자금만으로 단기간에 따라 만들기 어렵습니다.

## 각주 (심사 참고용 용어 설명)

1. **Fit Review** — 이용자가 미리 입력한 조건(국적·인종·피부타입 등)과 일치하는 작성자의 리뷰만 골라 보는 필터 기능. GLOU 자체 명칭.
2. **GLOU Check** — 영어 메뉴 유무, 외국 카드 결제 가능 여부, 한국 전화번호·예약 필요 여부, 혼자 방문 가능 여부, 가격대를 항목으로 표준화한 장소 정보. GLOU 자체 명칭.
3. **앰배서더(Ambassador)** — 리뷰와 콘텐츠를 꾸준히 생산하여 서비스가 공식 인증한 이용자. 국적별·지역별로 순위가 공개됨.
4. **TourAPI** — 한국관광공사가 개방한 관광정보 조회용 공공 API. 인증키를 발급받아 사용.
5. **D-4-1 비자** — 대학 부설 어학원 등에서 한국어를 배우는 어학연수생에게 발급되는 체류자격.
6. **ARC(Alien Registration Card, 외국인등록증)** — 91일 이상 체류하는 외국인이 발급받는 신분증. 은행 계좌 개설과 휴대전화 개통의 선행 조건.
7. **MVP(Minimum Viable Product, 최소기능제품)** — 핵심 기능만 구현하여 시장 반응을 확인하는 초기 제품.
8. **Firebase** — 구글이 제공하는 서버·데이터베이스·인증 통합 서비스. 서버를 직접 구축하지 않고 이용할 수 있음.
9. **온보딩(Onboarding)** — 신규 이용자가 서비스에 처음 가입하여 사용을 시작하기까지의 안내 과정.
10. **저맥락(Low-context) 화면** — 사전 지식이나 배경 설명 없이 화면에 보이는 것만으로 뜻이 통하도록 구성한 화면. 다국적 이용자를 대상으로 할 때 사용하는 설계 방식.

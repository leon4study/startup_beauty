## 0. 먼저 — 사람들이 왜 우리 앱을 켤까? (핵심 진입 이유 = JTBD)

> **"내 주변에 한국인이 진짜 가는 맛집·스팟 뭐 있지?"** (외국인 관점)

이게 1번 진입 동기. 그래서 **① 위치 기반 로컬 발견 → ② 내 국가·인종에 맞는 신뢰 리뷰**가 서비스의 심장. 나머지 기능은 이 둘을 돕는 것. (그래서 프로토타입 기본 카테고리를 **식당**으로, "🇰🇷 한국인 추천" 배지를 넣음)

## 1. Must-have (없으면 서비스가 성립 안 됨)

| 기능 | 왜 필수 | 상태 |
|---|---|---|
| **위치 기반 "내 주변" 발견** (지도+현위치) | JTBD 1번. Yelp·구글맵의 기본. | 🟡 지도 자리만(네이버/카카오 API 연동 TODO) |
| **검색** (장소·카테고리·지역) | Yelp 1순위 태스크. | ✅ |
| **카테고리 탐색** | 발견의 뼈대. | ✅ 아이콘 pill |
| **장소 상세** (주소·지도·영업시간·전화·길찾기·가격) | 결정에 필요한 정보. | 🟡 상세+지도·버튼 O, 영업시간·사진 ⬜ |
| **리뷰 + ⭐국가/인종 필터** | 우리 핵심 차별점. "나에게 맞는지". | ✅ |
| **정렬** (평점·리뷰수·거리) | 많은 결과 좁히기. | ✅ 거리 제외 |
| **외국인 친화 정보** (영어·한국번호 불필요·혼밥) | 외국인 최대 페인 직결. | ✅ 배지 |
| **리뷰 신뢰 장치** (협찬 차단·어뷰징 방지·가중치) | 한국 리뷰 불신이 존재 이유. [13](../../../data/research/market/13_review_integrity.md) | ⬜ |
| **로그인** (이메일, **한국번호 없이**) | 인증벽이 외국인 이탈 1위. 읽기는 무로그인. | ⬜ |
| **리뷰 작성** (별점·본문·사진) | UGC 없으면 데이터 안 쌓임. | ⬜ (다음 스코프) |
| **영어 우선 UI** | 기본 타겟이 외국인. | 🟡 |

## 3. Could-have (있으면 좋음)

- 리뷰 **자동 번역** (원문 유지 + 번역 토글 — 🅿️ 킵)
- **코스/동선 추천** (근처 뷰티+카페+맛집 묶기 — "현지인처럼")
- **예약 연결** (외부 딥링크; 직접 중개는 규제 주의)
- **개인화 추천** (내 국가·인종·이력 기반)
- **앰배서더 랭킹/리더보드** (참여 게임화)
- 푸시 알림 · 다국어(영어→베트남어…)

## 4. Won't-do now (지금 안 함 / 나중)

- 결제·예약 **직접 중개**, 배달, 금융·비자·의료 대행 (규제·범위) → 파트너 연결로
- 커뮤니티 피드·DM (콜드스타트·모더레이션 부담) → 커뮤니티는 리뷰가 모인 뒤

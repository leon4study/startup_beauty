# 창업아이템 개요 (GLOU)

초안 · 7/26 논의용 · 현준

## 한 줄로 말하면

GLOU는 외국인이 자기 **국가·인종에 맞는 믿을 리뷰**를 보고, **지역 인플루언서 콘텐츠**까지 즐기는 외국인용 로컬 플랫폼이다.

## 기능 · 기능 설명 · 수익원

| 기능 | 기능 설명 | 수익원 |
|---|---|---|
| **리뷰** | 국가·인종/피부·식성별 필터로 "나에게 맞는" 신뢰 리뷰 (원문 + 자동번역) | 리뷰 데이터 분석·리포트(B2B) |
| **개인화** | 국적·인종·식성 프로필로 맞춤 추천 (화장품 = 인종, 식당 = 국가) | 화장품·매장 광고 |
| **콘텐츠** | 지역 인플루언서 숏폼·웹진·큐레이션 소비 + 지역구 일짱 랭킹 | 구독 · 유료 콘텐츠 · 브랜드 캠페인 |
| **앰배서더** | 체험 → 리뷰·콘텐츠 → 활동 점수 → 지역 앰배서더 선정·인증 | 앰배서더 캠페인 운영비 |
| **제휴(Partner)** | 소상공인 다국어 콘텐츠 · 외국인 고객 · 방문/리뷰 성과 리포트 | 제휴비 · 예약/체험 성과 수수료 |

> 콘텐츠 기능의 세부 목록은 [디자인레퍼런스조사_0725.md](../03_조사/디자인레퍼런스조사_0725.md) 맨 위 "콘텐츠 기능 한눈에" 참고.

## 수익 구조 (마지막 정리)

- **B2C (외국인 사용자)** — 구독 · 유료 콘텐츠
- **B2B (지역 매장)** — 유료 프로필·광고 · 예약/체험 성과 수수료
- **B2B (브랜드)** — 국가별 앰배서더·인플루언서 캠페인
- **B2G (대학·지자체)** — 유학생 정착 프로그램 운영비 · 인사이트 데이터

> 재무 수치·단위(백만/10억 원)와 "앰배서더 캠페인이 수익인지 비용인지" 구분은 사업계획서에서 다시 산출 중이다. 이 개요는 **돈이 어디서 나오는지 '구조'만** 정리했고, 수치는 확정 후 채운다.

# GLOU 화면 트리 · 파일럿 시나리오

> 프로토타입 전체 화면과 이동 동선. 각 화면의 요소 → 누르면 어디로 가는지.
> (지금은 마크다운 트리 · 여유되면 Figma로 승격) · 딥링크는 [prototype/DEV_LINKS.md](../../../prototype/DEV_LINKS.md)
> 표기: `→` 이동 · **[모달]** 팝업 · **[오버레이]** 전체 위 레이어

---

## 1. 전체 네비게이션 (하단 5탭 = 모바일 / 상단 탭 = 데스크톱)

```
GLOU
├─ 📝 리뷰(홈/발견)      ?app 기본
├─ 💬 커뮤니티           ?app=community
├─ 🎬 쇼츠               ?app=shorts
├─ 🌟 앰배서더           ?app=ambassadors
└─ 👤 마이               ?mypage=1  (비로그인 → [로그인 모달])
   └─ ⚙️ 설정            ?settings=1
공통: 상단 GLOU=홈 · 로그인/You · (데스크톱)디자인 프리셋 스위처
```

## 2. 화면별 트리 (요소 → 이동)

### 📝 리뷰(홈/발견)  `/`
```
├─ 검색바(검색어·지역·검색)
├─ 프로필 필터(국적·인종)        [비로그인 시 표시]
├─ 카테고리 칩 5종               → 카테고리별 목록 (식당·화장품·병원·문화·여가)
├─ 필터행(국가·정렬·내주변) + 퀵칩(한국인추천·영어·번호불필요·혼자OK·저장한곳)
├─ 장소 카드 × N                → [카드] 장소 상세
└─ 지도(핀)                     → [핀] 장소 상세
```

### 장소 상세  `?place=p8`
```
├─ ← 목록으로                   → 리뷰 홈
├─ 히어로(이모지·이름·별점·가격·배지)
│   └─ 액션: 길찾기 · 전화 · 🤍저장
├─ 지도
├─ 🎈 이벤트 카드               → [신청하기] 이벤트 신청 [모달]      ← 파일럿 ③
├─ ℹ️ 이용정보 요약(영어·번호·혼밥·가격·현지추천)
├─ 영업정보(시간·메뉴·외부평점)
├─ 🌏 앰배서더 콘텐츠
├─ 별점 분포 · 인종별 평점
└─ 📝 리뷰 목록(내그룹만/전체·정렬·✍️리뷰쓰기)
    ├─ 리뷰 카드                → [카드] 후기 상세 [오버레이]        ← 파일럿 ⑤ 소비
    │   └─ 유용해요 · 🌐번역보기
    └─ ✍️ 리뷰 쓰기             → 리뷰 편집기 [전체화면]            ← 파일럿 ⑤ 작성
```

### 이벤트 신청  [모달]
```
├─ 이벤트 제목·혜택
├─ 방문 희망일 · 인원
└─ 신청하기                     → ✓ 신청됨 (실제 파일럿 = 구글폼 연결)
```

### 리뷰 편집기  [전체화면]  `?compose=p5`
```
├─ 취소 / 등록
├─ 별점(탭) · 내용 · 해시태그(추천칩) · 사진
└─ 등록                         → 리뷰 추가 → 장소 상세 리뷰 목록에 반영
```

### 후기 상세  [오버레이]  `?review=r1`
```
├─ ← 뒤로
├─ 📍 장소 보기                 → 장소 상세
├─ 작성자(아바타·국적·인종) · ★별점 · 본문 · 사진 · #해시태그
└─ 🌐 번역보기 · 👍 유용해요
```

### 💬 커뮤니티  `?app=community`
```
├─ 필터칩(전체·맛집·카페·뷰티·여행)
├─ 2단 격자 글카드 × N          → [카드] 글 상세
├─ ✍️ 글쓰기 FAB               → (로그인) 콘텐츠 올리기 [모달]
└─ 글 상세  ?post=po3
    ├─ ← 커뮤니티
    ├─ 히어로·본문·❤좋아요
    └─ 📍 장소 보기             → 장소 상세                        ← 콘텐츠→장소 전환
```

### 🎬 쇼츠  `?app=shorts`   (모바일: 상단바 숨김·몰입)
```
├─ 세로영상 피드(다음영상 스냅)
├─ 우측 레일: ♥ · 🔖 · 💬 · ↗공유
├─ 작성자 · 캡션
└─ 하단 쇼퍼블 장소 카드        → [장소 보기] 장소 상세             ← 콘텐츠→장소 전환
```

### 🌟 앰배서더  `?app=ambassadors`
```
├─ 내 랭킹 배너(로그인 시)
├─ 랭킹 리스트(행) × N          → [행] 인플루언서 프로필 [오버레이]
├─ 지도(도 → 클릭 시 시·구 드릴다운)
└─ 인플루언서 콘텐츠 피드
```

### 인플루언서 프로필  [오버레이]  `?profile=Jake`
```
├─ ← 뒤로
├─ 헤더(아바타·nick·게시물수·좋아요·팔로워)
└─ 인스타식 격자(커뮤+쇼츠, 🎬배지) → [셀] 게시물 상세 [오버레이]
```

### 👤 마이  `?mypage=1`  (빈 버전 `?mypage=empty`)
```
├─ ← 홈으로
├─ 프로필(You·국적·인종) + ⚙️설정 → 설정
└─ 탭: 게시물 / 리뷰 / 저장
    ├─ 게시물 격자              → [셀] 게시물 상세 [오버레이]
    ├─ 리뷰                     → [카드] 장소 상세
    └─ 저장                     → [카드] 장소 상세
```

### ⚙️ 설정  `?settings=1`
```
├─ ← 마이페이지
├─ 디자인 테마(오늘의집·Yelp·슬림) → 즉시 적용
└─ 프로필 수정 · 로그아웃
```

### 게시물 상세  [오버레이]   (프로필/마이 격자 → 셀 클릭)
```
├─ ← 뒤로
└─ 글: 본문·❤·📍장소 보기 / 쇼츠: 커버·캡션·📍장소 보기 → 장소 상세
```

### 로그인 / 가입  [모달]
```
└─ 이메일 · 닉네임 · 국적 → 로그인 (인종은 국적에서 자동)
```

## 3. 파일럿 한 사이클 (콘텐츠 → 신청폼 → 방문 → 리뷰)

| # | 단계 | 화면 | 유저 행동(클릭) | 딥링크(테스트) | 수집 데이터 | 전환지표 |
|---|---|---|---|---|---|---|
| ① | **콘텐츠 발견** | 커뮤니티/쇼츠 피드 · 후기 | 국적별 콘텐츠 소비 | `?app=community` · `?app=shorts` | 조회·저장·클릭 | 피드→상세 클릭률 |
| ② | **장소 전환** | 글/쇼츠/후기 → 📍장소 보기 → 장소 상세 | 이용정보 요약·이벤트 확인 | `?place=p8` | 상세 체류·저장 | 콘텐츠→상세 전환율 |
| ③ | **신청** | 이벤트 카드 → 신청하기 → [모달] | 방문 희망일·인원 입력 | (실제: 구글폼) | 신청 수·연락처 | 상세→신청 전환율 |
| ④ | **방문** | (오프라인) 제휴매장 + 쿠폰 | 방문·쿠폰 사용 | 방문 인증(코드·사진) | *미구현(선택)* | 신청→방문 전환율 |
| ⑤ | **리뷰** | 장소 상세 → ✍️리뷰쓰기 → 편집기 | 국적/피부 태그 리뷰 작성 | `?compose=p5` | 리뷰·태그·사진 | 방문→리뷰 전환율 |

→ ⑤ 리뷰가 **후기 콘텐츠**로 쌓여 다음 유저의 **①발견 신뢰도**를 올림 = 콜드스타트 극복 루프.

## 4. 테스트 시나리오 체크리스트 (한 사이클 클릭 검증)

- [ ] 커뮤니티 진입 → 글 카드 클릭 → 글 상세 열림
- [ ] 글 상세 → 📍장소 보기 → 장소 상세로 이동
- [ ] 장소 상세 → 🎈이벤트 카드 → 신청하기 → 신청 모달 → 신청 → ✓신청됨
- [ ] 장소 상세 → ✍️리뷰쓰기 → (로그인) → 편집기 → 별점·해시태그·등록
- [ ] 등록한 리뷰가 목록에 뜨는지 → 리뷰 카드 클릭 → 후기 상세 열림
- [ ] 쇼츠 → 하단 장소 카드 → 장소 상세 이동
- [ ] 앰배서더 랭킹 → 인플루언서 클릭 → 프로필 격자 → 게시물 클릭 → 상세
- [ ] 마이 → 게시물/리뷰/저장 탭 전환 · ⚙️설정에서 디자인 변경

## 5. 미구현/결정 필요
- **④ 방문 쿠폰·인증** (선택) — 쿠폰코드·방문 사진 인증
- **③ 신청폼** 실제 연결 — 1차 구글폼 URL(팀 확정) → 2차 인앱
- **모바일 네비 구조** — 현재(리뷰·커뮤니티·쇼츠·앰배서더·마이) vs 제안(발견·지도·＋작성·커뮤니티·마이)

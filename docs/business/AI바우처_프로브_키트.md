# AI 바우처 프로브 키트 (복붙 실행용)

> 목적: 로그인해서 **30분 안에** "이 도구가 우리가 원한 걸 진짜 주나"를 검증. 아래 입력값을 그대로 복붙하고, 확인 포인트를 스크린샷으로 남긴 뒤 판정(Y/N)만 채우면 됨.
> 순서: **① MindLens → ② 패스해커**(둘 다 결과가 시간에 쌓임 → 먼저 걸어두기) → ③ Legalize → ④ 랩투월드.
> 끝나면 결과를 팀/기획자에게 공유 → 실제에 맞게 [활용전략](AI바우처_활용전략.md)·[실행기획서](AI바우처_실행기획서.md) 재조정.

---

## ① MindLens — 먼저 걸어두기 (리포트 24~48h)
**로그인 → 무료 서비스**

**A. 샘플 리포트 열람** → 확인: 리포트에 *국적·체류기간·정성 인용문·권고안*이 있고, **영어권(미국 등) 표본 사례**가 있나? [스크린샷]

**B. 5명 미니 서베이 1회 신청** — 입력값 복붙:
```
[조사 목적]
영어권 서구(미국·영국) 20~30대 여성이 서울에서 K-뷰티 제품·살롱을 고르고 예약할 때 겪는 가장 큰 불편과,
'AI 성분 추천 + 영어 예약 대행 + 동네·테마 코스'를 묶은 서비스에 대한 지불의향 검증.

[타깃]  미국/영국 국적, 여성, 20~30대  ← ★ 이 지정이 되는지가 핵심 체크

[문항 3개]
1) 올리브영 제품 선택 / 한글 성분표 해독 / 살롱·피부과 예약 중 가장 어려운 것은?
2) "영어로 성분진단 → 로컬 매장 예약 → 반나절 K뷰티 코스"를 묶은 서비스에 월 얼마까지 낼 의향이 있나요? (US$ 범위)
3) 딱 하나만 고른다면 가장 원하는 기능은? (성분추천 / 예약대행 / 코스큐레이션)
```

**C. 5명 미니 인터뷰 1회 신청** — 프롬프트 복붙:
```
최근(또는 계획 중인) 한국 방문에서 K-뷰티 제품과 살롱을 어떻게 골랐나요?
무엇이 가장 막혔나요? 한국 블로그·인스타 리뷰(협찬 많음)를 신뢰하나요?
```

**✅ 판정**: (핵심) **타깃 국적을 미국/영국으로 지정 가능?** Y/N → N이면 *가용 국적 목록* 확인.
**기록**: 국적 지정 가능 ___ / 표본 규모 표시 ___ / 리포트 ETA ___

## ② 패스해커 레이더 — 먼저 세팅 (노출·사전예약 누적)
**로그인 → 새 랜딩/프로젝트 생성**

**A. 아이디어 입력** — 복붙:
```
GLOU — 영어권 외국인에게 (1) AI 성분·피부타입 추천, (2) 서울 로컬 뷰티매장(살롱·피부과·헤드스파) 영어 예약,
(3) 동네·테마 K뷰티 코스를 한 곳에서 제공. 타깃: 방한·서울 체류 영어권 20~30대 여성.
```

**B. 랜딩 영어 카피로 수정** ([실행기획서 §1 스켈레톤](AI바우처_실행기획서.md) 사용):
> Headline: *Your Seoul K-beauty bestie — skip the guesswork.* / CTA: *Join the waitlist → early access + free Seoul K-beauty starter guide.*

**C. ★ 핵심 체크 — 노출 타겟 설정 화면**: 국가를 **US/UK(해외)로 지정 가능한가?** 언어 영어 지원되나? [스크린샷]

**D. 사전예약 폼**: 필드에 *email · nationality · length of stay · interest(products/salon/course)* 추가 가능한가?

**✅ 판정**: 해외(영어권) 노출 가능 Y/N → N이면 *랜딩 폼만 쓰고 홍보는 우리 인플루언서·해외 커뮤니티로 직접*.
**기록**: 해외 노출 ___ / 영어 랜딩 ___ / 폼 커스터마이즈 ___

## ③ Legalize KR — 답변 품질·범위 확인 (7월 상시 이용)
**로그인 → AI 법률 질의** — 3개 복붙:
```
1) 미용 목적 방한 외국인을 피부과에 소개하고 병원에서 수수료를 받아도 되나요? 외국인환자 유치업 등록이 필요한가요?
2) 화장품 추천 서비스에서 "이 성분은 주름 개선에 효과적"이라고 표현하면 화장품법상 문제가 되나요?
3) 인플루언서가 협찬받은 제품 후기를 올릴 때 표시광고법상 무엇을 표시해야 하나요?
4) 아마존·틱톡 같은 해외 사이트에서 크롤링한 상품 후기 데이터를 상업 서비스에 사용하면 저작권·이용약관·개인정보(GDPR) 상 어떤 문제가 있나요? 합법적으로 쓰려면 어떻게 해야 하나요?
```
**B. 문서 생성**: 개인정보처리방침 1건 생성 → **영문 지원 여부** 확인.

**✅ 판정**: 답변에 **조문·판례 출처**가 붙나(신뢰성)? 영문 약관 되나? 해외 규제(MoCRA/EU) 답하나?
**기록**: 출처 표시 ___ / 영문 약관 ___ / 해외규제 커버 ___
**추가**: 관심법령(의료법·화장품법·전자상거래법·개인정보보호법) **개정 알림 구독** 걸어두기.

---

## ④ 랩투월드 — 화장품 도메인 깊이 확인
**로그인 → 키워드 입력**:
```
피부 타입별 화장품 성분 추천 시스템   (또는 영문: cosmetic ingredient recommendation by skin type)
```
**✅ 판정**: 리포트에 **화장품·성분 관련 논문·특허**가 실제로 나오나(딥테크만 나오지 않나)? md 다운로드 되나? 유용한가?
**기록**: 화장품 도메인 커버 ___ / 리포트 유용성(상/중/하) ___

---

## 끝나고 나서
1. 위 4개 **판정(Y/N)과 스크린샷/리포트**를 기획자(또는 이 대화)에 공유.
2. 결과에 따라 [활용전략](AI바우처_활용전략.md) §2 매트릭스와 [실행기획서](AI바우처_실행기획서.md) §0.5를 실제에 맞게 수정.
3. 통과한 도구는 유료 용량으로 확장(MindLens 유료 서베이 등), 깨진 도구는 대안으로 전환.

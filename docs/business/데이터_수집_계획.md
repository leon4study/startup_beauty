# GLOU 데이터 조달 방식

> GLOU가 서비스에 쓰는 데이터를 어떻게 확보하는지 정리했습니다. **자사(1차) 데이터를 중심으로, 공식 소스·제휴·라이선스**로 조달합니다.
> 작성 2026-07-02

## 원칙
1. **자사(1차) 데이터 우선** — 유저·매장·브랜드가 동의 하에 제공하는 데이터를 우리가 직접 모으고 소유합니다. 남이 못 베끼는 해자가 됩니다.
2. **외부 데이터는 공식 채널로** — 플랫폼 공식 API, 오픈 데이터베이스, 제휴, 라이선스 구매.
3. **개인정보는 최소·동의·익명** — 서구 유저 대상이라 GDPR을 기본값으로 설계합니다.

## 데이터별 조달
| 필요한 데이터 | 조달 방식 | 쓰이는 서비스 |
|---|---|---|
| 외국인 반응·후기 인사이트 | 자사 유저 반응(동의) · 브랜드가 맡긴 자사 후기 · TikTok/YouTube 공식 API · MindLens 패널 | ReactionLens · GapReport |
| 성분·효과·제품 정보 | EU CosIng · FDA · 식약처 성분 DB · Open Beauty Facts · 유저 스캔 | SkinMatch |
| 트렌드·수요 신호 | Google Trends · YouTube API · TikTok Creative Center · 관세청 수출통계 | Trend Index |
| 매장·예약 정보 | 매장 직접 제휴(정보 제공 동의) · 공식 지도 API | GLOU 본진 · 예약 |
| 외국인 수요 검증 | MindLens(동의 패널) · 사전예약(1차) · 자체 설문·인터뷰 | 수요 검증 |

## 서비스별 데이터 설계
- **SkinMatch(성분 추천)** — EU CosIng·FDA·Open Beauty Facts 같은 공개 성분 DB + 유저 바코드 스캔을 결합합니다. (Yuka가 검증한 모델)
- **ReactionLens(반응 인사이트)** — GLOU 앱 유저가 동의 하에 남긴 반응을 우리가 소유하고, 브랜드가 맡긴 자사 후기 데이터를 분석합니다. (Bazaarvoice가 검증한 1차 데이터 모델)
- **Trend Index(트렌드)** — 검색·해시태그·판매 신호 같은 집계 데이터를 공식 API로 다룹니다.

## 지금 당장 (자사 1차 데이터 만들기)
- **MindLens** — 동의된 외국인 패널의 반응 → ReactionLens·SkinMatch 데모의 데이터
- **사전예약 페이지** — 관심 고객 = 우리 첫 자사 데이터
- **공식 API + 관세청 통계** — 트렌드 신호
→ 이걸 우리 분석 엔진에 넣으면 9월 발표 근거가 나옵니다.

## 로드맵
- **지금**: 공식 API + 자사 설문·사전예약으로 첫 데이터 확보 → 엔진에 투입해 데모.
- **R1~R2**: 브랜드 1~2곳 제휴 → 브랜드 자사 후기 분석 + 유저 데이터 축적 시작.
- **이후**: 자사 데이터가 쌓이며 플라이휠 가동 → 라이선스·제휴로 확대.

## 개인정보 설계
- 개인정보처리방침·이용약관 준비, 최소 수집·동의·익명 처리, 삭제 요청 대응.
- 서구 유저 → GDPR 합법근거(동의/계약) 확보, 국외이전 고지.

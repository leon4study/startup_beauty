## 0. 읽는 법 (1분)
- **우리의 진짜 해자 = 특정 서비스가 아니라 3개 재사용 자산**: ①180개국 외국인 인플루언서 네트워크 ②K-뷰티 리뷰(아마존·틱톡) RAG + 성분 498노드 지식그래프 + 화학·약학 ③뷰티 인플루언서 콘텐츠력. → **같은 자산을 여러 서비스로 재배치**하는 게 전략.
- **타겟**: 1차 = 영어권 서구(미국 주도+영국+영어권 유럽/오세아니아) 20–30대 여성 / 2차 = 서울 거주 외국인·유학생. (중국=레드오션, 의도적 후순위)
- **점수**: 6축(시장수요·경쟁빈틈·팀자산적합·수익성·실행리스크·모두의창업적합), 정성 추정. **S/A/B/C 등급**. ⚠️ 점수는 가설 — 상위는 인터뷰로 검증(Phase3) 후 확정.
- **모두의창업 태그**: A(AI·빅데이터) B(Bio-Health) C(Contents·Culture) D(딥테크) E(ESG) F(Food-Tech).

## 1. 🏆 종합 추천 — 듀얼트랙 포트폴리오

> 핵심 통찰: **하나의 엔진(리뷰 RAG+성분그래프)을 B2C(GLOU)와 B2B(데이터)로 동시 수익화.** B2B는 *데모를 당장 만들 수 있어* 모두의창업 "증거 기반 차별화"에 최적이고, B2C(GLOU)는 유저·데이터를 모아 B2B에 환류한다.

```
[공유 엔진] K-뷰티 리뷰 RAG + 성분 498노드 그래프 + 인플루언서 ER모델 (Kbeauty_Analysis 보유)
   │
   ├─ 🅑 B2C 본진 (유저·데이터 획득) ── GLOU: F1 코스큐레이션 + F10 퍼스널쇼퍼 + F3 예약컨시어지
   ├─ 🅐 B2B 데이터 (수익·해자·데모) ── ReactionLens · SkinMatch · CreatorMatch · GapReport
   └─ 🅛 즉시실행 (트랙션 증거) ────── G9 뉴스레터 · G6 멤버십 · PillCheck 성분스캐너
```

## 4. ⚠️ 규제 가드레일 (반드시 숙지 — 서비스 설계 전 체크)
1. **의료 송객 수수료 = 위법** — 강남언니 형사처벌 선례. 피부과·성형(A3·B6·E2·E9·F4·F5)은 **광고·구독·리드젠 모델**로만, 직접 알선 시 **외국인환자 유치업 등록**(시·도, 3년, 실적보고) + 복지부 고시 수수료 상한 + 의료광고 사전심의 필수.
2. **해외 화장품 규제** — 美 선크림=OTC 의약품(D2C 소싱 불가, 큐레이션만), **de minimis $800 면세 폐지(2025-08-29)+15% 관세**, **US MoCRA**(시설등록)·**EU CPNP**(역내 RP). → **소싱보다 "규제 부담 없는 큐레이션·송객"이 day1 정답.**
3. **EU 그린워싱 지침(2024/825) 2026-09-27 시행** — 클린/내추럴 자작 클레임 증빙 의무. → G4·C7의 **수요 트리거이자 타이밍 호재**.
4. **본인인증 변화** — 2026-06 네이버 여권인증으로 "외국인 예약 불가"가 부분 완화 → "예약 가능"만으론 차별화 부족, **큐레이션·신뢰가 해자**.
5. **화장품 광고** — 효능 과장 표현 규제(화장품법). **표시광고법** — 협찬 시 "광고/협찬" 명시.

# 서비스별 데이터 조달 점검

> 아이디어를 고를 때 **"이 데이터를 실제로 구할 수 있나"**를 먼저 본다. 어려우면 ① 제외하거나 ② 필요한 협업을 명시하거나 ③ 조달 방법·기획을 함께 적는다.
> 조달 방식 원칙은 [데이터_수집_계획.md](데이터_수집_계획.md) 참조. 작성 2026-07-02

## 신호등
- 🟢 **확보 쉬움** — 자사 1차 데이터 or 공개 DB·공식 API로 바로.
- 🟡 **제휴·구축 필요** — 매장·브랜드 제휴 또는 자사 1차 데이터 구축이 전제(방법 명시).
- 🔴 **조달 난망** — 데이터가 없거나 규제로 막힘 → 제외·보류.

## 핵심 6개
| 서비스 | 필요 데이터 | 난이도 | 조달 방법 / 필요 협업 |
|---|---|---|---|
| **ReactionLens** | 제품 반응·후기 | 🟡 | ①자사 앱 유저 반응(동의 수집) ②**브랜드 1~2곳과 "우리 제품 반응 분석" 제휴 → 브랜드가 자사 후기 제공.** 초기 데모는 MindLens 패널 반응으로 대체 |
| **SkinMatch** | 성분·효과 DB | 🟢 | EU CosIng·FDA·Open Beauty Facts(공개) + 유저 스캔. **협업 불필요** |
| **GLOU 본진**(코스·예약) | 매장 정보·예약 슬롯 | 🟡 | **로컬 뷰티/카페/맛집 매장과 직접 제휴**(정보·예약 제공). 초기엔 컨시어지(수동 예약 대행)로 데이터 없이 시작 가능. → **매장 온보딩이 사업의 핵심 과제** |
| **CreatorMatch** | 인플루언서 성과 | 🟢 | 우리 180개국 네트워크(1차) + YouTube/TikTok 공식 API 공개 지표. 협업 최소 |
| **G4 그린워싱 검증** | 성분·클레임·규제 DB | 🟡 | 공개 규제 DB(CosIng·EU) + **브랜드가 자사 제품 정보 제공(검증 의뢰 = 협업)** |
| **뉴스레터/멤버십** | 콘텐츠·커뮤니티 | 🟢 | 우리가 직접 제작·운영. **협업 불필요** — 지금 바로 시작 |

## 카테고리별 나머지
| 서비스 | 필요 데이터 | 난이도 | 조달 방법 / 필요 협업 / 판정 |
|---|---|---|---|
| PillCheck(성분 스캐너) | 성분·안전 DB | 🟢 | 공개 성분 DB + 유저 스캔 (SkinMatch와 동일) |
| Trend Index | 트렌드 신호 | 🟢 | Google Trends·YouTube·TikTok Creative Center 공식 API |
| UGC Bridge(크리에이터 장터) | 크리에이터·브랜드 | 🟢🟡 | 우리 네트워크가 공급(1차). 브랜드는 셀프서브로 유입 |
| 살롱 예약(곱슬 전문 등) | 살롱 정보·예약 | 🟡 | **살롱과 직접 제휴**(포트폴리오·슬롯 제공). 초기 컨시어지로 대체 |
| 정착 도우미 | 통신·부동산·행정 | 🟡 | **통신사·부동산·은행 제휴(CPA)** — 제휴가 곧 수익원 |
| 식이필터 다이닝 | 식당 메뉴·성분 | 🟡 | 식당 제휴 + 메뉴 성분은 크라우드소싱·식당 제공. 대량 확보가 관건 |
| 의료 내비/클리닉 | 병원 정보·가격 | 🔴→🟡 | **병원 제휴 필요 + 의료광고·외국인환자 유치업 규제 선결**. 초기엔 비의료(정보·통역)만 |
| 의료관광 패키지 | 병원·시술 | 🔴 보류 | 유치업 등록·수수료 상한 규제 → 2단계로 미룸 |

## 결론 — 데이터 난이도로 본 우선순위
- **🟢 지금 바로 (데이터 걱정 없음)**: SkinMatch · PillCheck · Trend Index · 뉴스레터/멤버십 · CreatorMatch → **데모·트랙션을 가장 빨리 만들 수 있는 라인.**
- **🟡 제휴가 곧 사업 (방법 명시 완료)**: ReactionLens(브랜드+자사유저) · GLOU 본진(매장 제휴) · 살롱예약(살롱 제휴) · 정착(통신·부동산 제휴) · 식이필터(식당 제휴). → *제휴처 온보딩 계획을 사업계획에 반드시 포함*. 초기엔 컨시어지(수동)로 데이터 없이 검증 가능.
- **🔴 보류/제외**: 의료관광 송객(유치업·수수료 규제), 순수 외부 리뷰 수집에만 의존하는 아이디어.

> 규칙: **🟢부터 착수해 데이터·트랙션을 먼저 쌓고**, 🟡는 *제휴 1곳*으로 파일럿하며 확장한다. 🔴는 규제·제휴가 풀리기 전엔 손대지 않는다.

## 3. ⚠️ 반면교사 (죽은/고전한 사례)
- **Fakespot** — 아마존 공개 리뷰 UI 래핑 → 아마존 항의 → 앱스토어 퇴출 → **2025 폐업**. (리뷰 스크래핑 상업화의 실패)

## 5. GLOU 포지셔닝 (빈틈에서)
> **"추천만 하는 Seoul Sister와 예약만 하는 Creatrip 사이"** — AI 성분·효과 진단 → 서울 로컬 매장 예약 → 동네·테마 코스를 **하나의 흐름**으로 잇는다. 여기에 **영어권 서구 타겟 + "현지인처럼 즐기는 법"(인플루언서·콘텐츠 자산)** 을 얹어 아무도 못 채운 자리를 잡는다.
- 데이터는 합법(자사 1차 + 공식 API + 브랜드 제공), 의료는 광고 모델 — 경쟁사 교훈 그대로 반영.
